# First Revvi Class pilot

The binding activation procedure is [Classes-only pilot activation](operations/sandbox-business-pilot.md).

The code path is ready to collect controlled evidence and will fail closed until that package is complete. Repository fixtures, automated tests, the retained Appointment prototype, and sandbox evidence from another Site, Location, Offer, mapping version, or fulfilment mode cannot activate a pilot.

For the first partner, choose one existing approved Class family at one Location, one exact set of Memberstack plan IDs, and one fulfilment mode whose payment, entitlement, or approved-unpaid evidence gate is already verified. Complete every evidence category in the runbook, activate the exact mapping, and retain the generated evidence-set digest in the handover record.

Production must be activated separately from sandbox and must repeat the complete controlled package.
